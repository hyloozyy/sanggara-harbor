# Bundled fonts

All fonts are under the SIL Open Font License 1.1 (the `OFL.txt` beside each family) and were
downloaded from the official Google Fonts repository (https://github.com/google/fonts, `ofl/`).
They are served from these local files; the game makes no font requests over the network.

| Family | Files | Used for |
|---|---|---|
| Bebas Neue (Dharma Type) | `bebasneue/` | display: titles, event banners (WASTED, MISSION PASSED), district names, speaker names |
| Barlow (Jeremy Tribby) | `barlow/` | body text: HUD, menus, subtitles, dialogue, map cards |
| Barlow Condensed (Jeremy Tribby) | `barlowcondensed/` | menu buttons, labels, small caps lines |
| Saira Stencil One (Omnibus-Type) | `sairastencilone/` | numbers: money, ammo, speedometer, timers |
